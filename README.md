# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт учебного интернет-магазина:

- пять связанных страниц с единой навигацией и якорными ссылками;
- семантическая разметка: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`;
- карточки товаров, таблица характеристик, форма заявки и модальное окно `<dialog>`;
- внешний CSS-файл с переменными, состояниями, Flexbox, Grid и БЭМ-именованием;
- позиционирование: `relative`, `absolute`, `sticky`, `fixed`, `z-index`.

## Структура проекта

- `index.html` — главная страница: hero-блок, преимущества, популярные товары;
- `catalog.html` — каталог товаров с блоком фильтров;
- `product.html`, `product-2.html`, `product-3.html` — карточки трёх товаров: изображение, описание, цена, таблица характеристик;
- `order.html` — страница оформления заявки с формой;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — скрипт модального окна и валидации формы заявки;
- `images/` — папка для изображений: `product-1.svg`, `product-2.svg`, `product-3.svg` — изображения товаров, `preview.jpg` — превью сайта;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров.

## Позиционирование

В проекте используются:

- `position: relative` — карточка товара как точка отсчёта для бейджа;
- `position: absolute` — бейджи «Хит» и «Скидка» в углу карточки;
- `position: sticky` — шапка сайта остаётся вверху экрана при прокрутке;
- `position: fixed` — кнопка «Наверх» в правом нижнем углу окна;
- `z-index` — шапка и кнопка «Наверх» отображаются поверх содержимого страницы.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `section` — универсальный раздел страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `filters-form` — форма фильтров;
- `product` — страница товара;
- `product-table` — таблица характеристик;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `success-message` — сообщение об успешной отправке;
- `button` — кнопка;
- `to-top` — фиксированная кнопка «Наверх»;
- `site-footer` — подвал сайта.
