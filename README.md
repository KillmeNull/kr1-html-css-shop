# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт учебного интернет-магазина:

- семь связанных страниц с единой навигацией и якорными ссылками;
- семантическая разметка: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`;
- карточки товаров, таблица характеристик, форма заявки и модальное окно `<dialog>`;
- внешний CSS-файл с переменными, состояниями, Flexbox, Grid и БЭМ-именованием;
- позиционирование: `relative`, `absolute`, `sticky`, `fixed`, `z-index`.

## Самостоятельные доработки

Сверх пошаговых методических указаний в проекте сделано следующее.

Страницы и блоки:

- у каждого товара своя страница (`product.html`, `product-2.html`, `product-3.html`), а не одна общая;
- блок отзывов на главной странице: карточки на `figure`, `blockquote` и `figcaption`, выстроенные через CSS Grid;
- собственная цветовая схема: жёлтый основной цвет с тёмным текстом, тёмно-янтарные ссылки и рамки, тёплые нейтральные фоны; все цвета заданы переменными в `:root`;
- собственное название и логотип сайта.

Карточки товаров:

- фотографии товаров в одинаковой области 4:3 (`aspect-ratio`, `object-fit: contain`), чтобы снимки разных пропорций не ломали сетку;
- бейджи «Хит» и «Скидка» и два модификатора карточки: `product-card--featured` и `product-card--discount`;
- название товара в карточке — ссылка на его страницу.

Форма заявки:

- форма доступна и в модальном окне, и на отдельной странице `order.html`; обе обслуживает один скрипт;
- ошибочные поля получают атрибут `aria-invalid` и красную рамку;
- после отправки показывается сообщение об успехе, страница прокручивается к нему;
- название товара, выбранного кнопкой «Заказать», записывается в скрытое поле формы.

Навигация:

- активный пункт меню выделяется модификатором `site-nav__link--active`;
- хлебные крошки в три уровня на страницах товаров;
- липкая шапка и отступ `scroll-padding-top`, чтобы шапка не закрывала раздел при переходе по якорю;
- фиксированная кнопка «Наверх» и подсветка раздела, к которому выполнен переход (`:target`).

Доступность:

- видимый фокус (`:focus-visible`) у ссылок, кнопок и полей формы;
- у каждого поля формы есть подпись `label`, у изображений — текст `alt`, у блоков навигации — `aria-label`;
- оценка в отзывах продублирована текстом в `aria-label`;
- цвета текста, ссылок, кнопок и логотипа подобраны с контрастом не ниже 4,5:1.

CSS:

- по БЭМ оформлены и блоки, которых нет в методических указаниях: `filters-form`, `product`, `product-table`, `reviews`, `review`, `to-top`;
- слои `z-index` и фирменные цвета вынесены в переменные `:root`;
- у кнопок-ссылок цвет текста при наведении задан явно, иначе его перекрывало общее правило `a:hover`.

Дополнительно:

- Open Graph-теги на всех страницах и изображение-превью `images/preview.jpg` для отображения ссылки в мессенджерах.

## Структура проекта

- `index.html` — главная страница: hero-блок, преимущества, популярные товары, отзывы;
- `catalog.html` — каталог товаров с блоком фильтров;
- `product.html`, `product-2.html`, `product-3.html` — страницы товаров «Калькулятор 1С», «Коробочка 1С:Бухгалтерия» и «Курс 1С разработчик»: фото, описание, цена, таблица характеристик;
- `order.html` — страница оформления заявки с формой;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — скрипт модального окна и валидации формы заявки;
- `images/` — папка для изображений: `product-1.jpg`, `product-2.jpg`, `product-3.jpg` — фотографии товаров, `preview.jpg` — превью сайта;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров.

## Позиционирование

В проекте используются:

- `position: relative` — карточка товара как точка отсчёта для бейджа;
- `position: absolute` — бейджи «Хит» и «Скидка» в углу карточки;
- `position: sticky` — шапка сайта остаётся вверху экрана при прокрутке;
- `position: fixed` — кнопка «Наверх» в правом нижнем углу окна;
- `z-index` — шапка и кнопка «Наверх» отображаются поверх содержимого страницы.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `section` — универсальный раздел страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `filters-form` — форма фильтров;
- `product` — страница товара;
- `product-table` — таблица характеристик;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `reviews` — блок отзывов;
- `review` — карточка отзыва;
- `success-message` — сообщение об успешной отправке;
- `button` — кнопка;
- `to-top` — фиксированная кнопка «Наверх»;
- `site-footer` — подвал сайта.
